# Stage 1 验证结果分析文档

## 概述

本文档分析 Stage 1 MAE 预训练的验证结果，包括编码器特征评估和重建质量指标。这些指标用于评估 Stage 1 训练效果，并判断是否适合进入 Stage 2 训练。

---

## 一、模型配置信息

### 1.1 基本配置

- **`image_size=224`**: 输入图像的尺寸（224×224 像素）
  - 这是 ViT 模型的标准输入尺寸
  - 所有输入图像会被 resize 到这个尺寸

- **`patch_size=16`**: 每个 patch 的尺寸（16×16 像素）
  - ViT 将图像分割成多个不重叠的 patch
  - 每个 patch 会被展平并投影到特征空间
  - patch_size=16 意味着每个 patch 包含 16×16=256 个像素

- **`num_patches=196`**: patch 的总数量
  - 计算公式：`num_patches = (image_size / patch_size)² = (224 / 16)² = 14² = 196`
  - 图像被分割成 14×14 的 patch 网格
  - 每个 patch 是一个 16×16 像素的区域

- **`num_channels=4`**: 输入图像的通道数
  - 4个通道分别对应：
    1. **Intensity**（总光强）
    2. **DoLP**（Degree of Linear Polarization，偏振度）
    3. **sin(2*AoLP)**（偏振角的正弦表示）
    4. **cos(2*AoLP)**（偏振角的余弦表示）

### 1.2 Patch Embeddings 配置

- **`patch_embeddings.projection.weight.shape: [768, 4, 16, 16]`**
  - 这是卷积层的权重形状
  - `768`: 输出特征维度（ViT-Base 的 hidden_size）
  - `4`: 输入通道数（4通道偏振图像）
  - `16, 16`: 卷积核尺寸（与 patch_size 一致）
  - 这个卷积层将每个 16×16×4 的 patch 投影成 768 维的特征向量

- **`patch_embeddings.projection.kernel_size: (16, 16)`**: 卷积核尺寸
- **`patch_embeddings.projection.stride: (16, 16)`**: 步长
  - stride=16 确保 patches 之间不重叠
  - 每个 16×16 区域被独立处理

### 1.3 位置编码

- **`position_embeddings.shape: [1, 197, 768]`**
  - `197`: 196 个 patch tokens + 1 个 CLS token
  - `768`: 特征维度
  - 位置编码为每个 patch 和 CLS token 提供位置信息
  - ViT 使用可学习的位置编码（而不是固定的正弦编码）

## 二、编码器特征评估

### 2.1 特征形状

- **`patch_embeddings 输出: [1, 196, 768]`**
  - `1`: batch size
  - `196`: patch 数量（14×14 网格）
  - `768`: 每个 patch 的特征维度

- **`绕过 mask 的 ViT 输出: [1, 197, 768]`**
  - `197`: 196 个 patch tokens + 1 个 CLS token
  - 这是 Stage 2 需要的完整特征（包含所有 patches）
  - CLS token 用于全局表示，patch tokens 用于局部特征

- **`MAE vit() 输出（应用 mask）: [1, 99, 768]`**
  - MAE 训练时只处理可见的（unmasked）patches
  - mask_ratio=0.5 意味着 50% 的 patches 被掩码
  - 可见 patches 数量：196 × 0.5 = 98（加上 CLS token = 99）
  - 这个输出用于 MAE 的重建任务，但 Stage 2 需要完整特征

### 2.2 特征统计信息

#### 特征均值（Mean）

- **当前值：0.0386**
- **含义**：编码器输出特征的均值接近 0
- **解释**：
  - ViT 使用 LayerNorm，会强制特征的均值接近 0
  - 均值接近 0 是正常的，表示特征分布是中心化的
  - 理想范围：`|mean| < 0.5`（当前值在理想范围内）

#### 特征标准差（Std）

- **当前值：2.3056**
- **含义**：编码器输出特征的标准差
- **解释**：
  - 标准差反映了特征的分散程度
  - 经过多层 transformer 后，方差可能累积
  - 理想范围：`1.0 < std < 3.0`（当前值略高但可接受）
  - 如果标准差过大（>5.0），可能表示梯度爆炸或训练不稳定

#### 特征范围（Range）

- **当前值：[-15.3065, 22.5455]**
- **含义**：编码器输出特征的最小值和最大值
- **解释**：
  - 范围较大，但这是正常的（transformer 特征可以有很大的动态范围）
  - LayerNorm 会将特征归一化，但不会限制值的范围
  - 如果范围过大（如 [-100, 100]），可能表示特征分布异常

#### 分布状态

- **当前状态：✓ 特征分布正常，适合 Stage 2**
- **判断标准**：
  - `|mean| < 0.5` 且 `0.5 < std < 5.0`：特征分布可接受
  - `|mean| < 0.1` 且 `1.0 < std < 3.0`：特征分布理想（当前值接近）
- **意义**：
  - 特征分布正常意味着编码器已经学习了有效的表示
  - 可以安全地用于 Stage 2 训练

## 三、重建质量指标

### 3.1 MSE（Mean Squared Error，均方误差）

**定义**：`MSE = (1/N) Σ(原始值 - 重建值)²`

- **单位**：无量纲（因为输入值已经归一化到 [0, 1]）
- **值越小越好**：MSE=0 表示完美重建
- **当前结果**（多样本平均）：
  - Intensity: 0.005784
  - DoLP: 0.004907
  - sin(2*AoLP): 0.007352
  - cos(2*AoLP): 0.021915
  - Mean: 0.009990

**分析**：
- cos(2*AoLP) 的 MSE 最大（0.021915），说明这个通道的重建难度较高
- DoLP 的 MSE 最小（0.004907），说明偏振度信息重建较好
- 平均 MSE 为 0.009990，表示重建误差约为 1%

### 3.2 PSNR（Peak Signal-to-Noise Ratio，峰值信噪比）

**定义**：`PSNR = 10 × log₁₀(MAX² / MSE)`，其中 MAX=1（归一化值）

- **单位**：dB（分贝）
- **值越大越好**：PSNR=∞ 表示完美重建
- **经验阈值**：
  - PSNR > 30 dB：优秀
  - PSNR > 25 dB：良好
  - PSNR > 20 dB：可接受
  - PSNR < 20 dB：较差

**当前结果**（多样本平均）：
- Intensity: 22.39 dB（良好）
- DoLP: 23.14 dB（良好）
- sin(2*AoLP): 21.80 dB（良好）
- cos(2*AoLP): 17.11 dB（较差）
- Mean: 20.22 dB（可接受）

**分析**：
- cos(2*AoLP) 的 PSNR 最低（17.11 dB），与 MSE 结果一致
- DoLP 的 PSNR 最高（23.14 dB），重建质量最好
- 平均 PSNR 为 20.22 dB，处于"可接受"水平

### 3.3 各通道重建难度分析

#### Intensity（总光强）

- **MSE**: 0.005784（中等）
- **PSNR**: 22.39 dB（良好）
- **特点**：强度信息是基础特征，重建相对容易

#### DoLP（偏振度）

- **MSE**: 0.004907（最小）
- **PSNR**: 23.14 dB（最高）
- **特点**：偏振度信息重建质量最好，说明模型很好地学习了偏振特性

#### sin(2*AoLP)（偏振角正弦）

- **MSE**: 0.007352（中等偏高）
- **PSNR**: 21.80 dB（良好）
- **特点**：重建质量可接受，略低于 DoLP

#### cos(2*AoLP)（偏振角余弦）

- **MSE**: 0.021915（最大）
- **PSNR**: 17.11 dB（最低）
- **特点**：
  - 重建难度最高，可能是因为：
    1. cos(2*AoLP) 与 sin(2*AoLP) 存在相关性，需要模型学习两者之间的约束
    2. 相位信息的重建本身比幅度信息更困难
    3. 某些场景下，cos(2*AoLP) 的数值范围可能更极端

## 四、不同场景的差异

### 4.1 场景差异的原因

不同场景（scene_id）的验证结果可能存在差异，主要原因包括：

1. **场景复杂度**
   - 简单场景（如纯色背景）：重建更容易，PSNR 更高
   - 复杂场景（如纹理丰富、边缘多）：重建更困难，PSNR 可能较低

2. **反光强度**
   - 高反光场景：偏振信息变化剧烈，重建难度高
   - 低反光场景：偏振信息平稳，重建相对容易

3. **纹理特征**
   - 均匀纹理：重建误差小
   - 非均匀纹理（边缘、细节多）：重建误差大

4. **光照条件**
   - 光照均匀：重建质量好
   - 光照不均匀（阴影、高光）：重建质量可能下降

### 4.2 如何评估场景差异

- **查看单个样本指标**：`--num_examples=1` 时，可以查看单个场景的详细指标
- **计算多样本平均**：`--num_examples>1` 时，会输出平均指标，更能反映整体性能
- **对比不同场景**：分别对不同 scene_id 运行验证，对比结果

| 质量等级 | PSNR 范围 | 建议 |
|---------|----------|------|
| **优秀** | PSNR ≥ 25.0 dB | ✓ 编码器质量很好，可以直接用于 Stage 2 |
| **良好** | 20.0 ≤ PSNR < 25.0 dB | ✓ 编码器质量良好，可以用于 Stage 2 |
| **中等** | 15.0 ≤ PSNR < 20.0 dB | ⚠ 编码器质量中等，建议检查训练配置或增加训练轮数 |
| **较差** | PSNR < 15.0 dB | ❌ 编码器质量较差，建议重新训练 Stage 1 |
